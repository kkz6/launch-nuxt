# Overview

Welcome to **launchctl** - the simplest way to deploy and manage your servers without DevOps expertise.

## What is launchctl?

launchctl is a server management platform that helps you:

- **Provision servers** from popular cloud providers (DigitalOcean, Hetzner, Vultr, AWS, Linode)
- **Deploy applications** with Git-based workflows
- **Manage databases** including MySQL, PostgreSQL, Redis, and MongoDB
- **Secure your sites** with free SSL certificates from Let's Encrypt
- **Monitor your infrastructure** with built-in dashboards

## Quick Start

### 1. Create an Account

Sign up for a free account at [launchctl.io](https://launchctl.io/register). No credit card required for the 14-day trial.

### 2. Connect a Server

You can either:
- **Connect a cloud provider** and let launchctl provision servers for you
- **Connect an existing server** using SSH credentials

### 3. Deploy Your First Site

Once your server is ready:

1. Navigate to **Sites** in your server dashboard
2. Click **Add Site**
3. Connect your Git repository
4. Configure your deployment settings
5. Deploy!

## Key Features

### Server Management

- One-click server provisioning
- Multiple PHP versions support
- Nginx configuration management
- SSH key management
- Firewall rules

### Site Deployments

- Git-based deployments (GitHub, GitLab, Bitbucket)
- Zero-downtime deployments
- Environment variables management
- Deployment hooks
- Rollback support

### Database Management

- Create and manage databases with one click
- Support for MySQL, PostgreSQL, Redis, MongoDB
- Automatic backups
- Database user management

### Security

- Free SSL certificates with auto-renewal
- Firewall management
- SSH key authentication
- Two-factor authentication
